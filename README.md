# Shilin Sun | Academic Homepage

Personal academic homepage based on the [Academic Homepage Template](https://github.com/w-r-s/academic-homepage-template).

The profile, education history, and publication list are populated from the public ORCID record for [Shilin Sun](https://orcid.org/0009-0007-8897-3737). Duplicate records have been merged by DOI or title. Topic filters and pagination keep the publication list compact. Figures shown beside papers are original figures from the linked publisher or paper record. A conference paper with a listed publication date of November 10, 2026 is marked forthcoming as of the page's November 6, 2026 update.

## Publish with GitHub Pages

1. Open the repository **Settings** tab.
2. In the left sidebar, open **Pages**.
3. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
4. Set the branch to **`main`** and the folder to **`/(root)`**, then click **Save**.
5. Wait for the Pages deployment to finish. The site will be available at <https://shilinsun.github.io/ssl/>. GitHub shows the current deployment status and link in **Settings → Pages**.

After pushing changes to `main`, GitHub Pages will rebuild the site automatically.

## Preview locally

```bash
python3 -m http.server 8080 --bind 127.0.0.1
```

Then open <http://127.0.0.1:8080>.
